2. Sube el CONTENIDO de esta carpeta a la raíz del repositorio de GitHub (no subas una carpeta contenedora adicional).
3. En GitHub > Settings > Pages, verifica que la fuente publique desde la misma rama y carpeta donde quedó index.html.
4. Confirma que `index.html` y la carpeta `js` estén al mismo nivel.
5. Espera la publicación y recarga la página con Ctrl + F5.
